🎓 Git & GitHub Hands-on Workshop

Welcome to the Git Quest workshop — a short, practical series of tasks that teach Git and GitHub through hands-on exercises. Work through the tasks in order. Each task has an associated Issue template so students can open an Issue, create a branch, and submit a Pull Request for review.

Tasks

- Task 1 — Git Basics: `tasks/task-1.md` (Issue: "Task 1 — Git Basics")
- Task 2 — Branching, Merging & Collaboration: `tasks/task-2.md` (Issue: "Task 2 — Branching & Merge Conflicts")
- Task 3 — Advanced Git Operations: `tasks/task-3.md` (Issue: "Task 3 — Advanced Git")
- Task 4 — Final Team Challenge: `tasks/task-4.md` (Issue: "Task 4 — Team Challenge")

How to use this repo in the workshop

1. Create a new branch for your task: `git checkout -b feature/<your-name>-task-<n>`
2. Follow the instructions in the corresponding `tasks/task-<n>.md` file.
3. Open an Issue using the template for the task (available when creating a new Issue on GitHub).
4. Push your branch and open a Pull Request. Assign a reviewer and follow the PR checklist.

See `CONTRIBUTING.md` for a condensed guide (branch naming, commit messages, PR & review checklist, and conflict resolution steps).

Have fun and learn by doing!
